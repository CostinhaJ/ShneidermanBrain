# 06-Registo

Um handoff por tarefa concluída, parcial ou bloqueada. É a memória que os agentes seguintes leem para continuar sem repetir trabalho.

- Nome: `AAAA-MM-DD-OBJ-nnn-slug.md`. Cria com a skill `fechar-tarefa`.
- Escreve só o teu handoff. Nunca edites o de outro agente: se discordas, cria um novo que o referencie.
- Conteúdo mínimo: o que fez, o que mudou (ficheiros), como foi verificado, o que falta, lacunas novas, skills candidatas.
- Estado `concluido` só se o critério de sucesso do brief foi cumprido **e** verificado. Caso contrário, `parcial` ou `bloqueado`, com a razão.
