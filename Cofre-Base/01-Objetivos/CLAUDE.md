# 01-Objetivos

- Um ficheiro por objetivo: `OBJ-nnn-slug.md`, criado com a skill `novo-objetivo` a partir do template.
- O brief é o contrato do agente: objetivo, critério de sucesso **verificável**, ordem de leitura, skills, âmbito (pode ler / pode escrever / fora de âmbito) e entregáveis.
- Só o orquestrador ou o utilizador mudam `estado` (`aberto`, `em-curso`, `concluido`). Os outros agentes reportam no handoff.
- Se o critério de sucesso não se consegue verificar com um comando, um teste ou uma fonte, reescreve-o antes de delegar.
