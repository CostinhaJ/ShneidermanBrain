# Skills

Cada skill é uma pasta com um `SKILL.md` (frontmatter `name` + `description`, depois instruções). O formato é compatível com as skills do Claude Code. A `description` diz **quando** usar a skill; é com ela que o agente decide.

| Skill | Quando usar |
|---|---|
| [[40-skills/create-project/SKILL\|create-project]] | Criar um projeto ou subprojeto novo |
| [[40-skills/triage-inbox/SKILL\|triage-inbox]] | Classificar e mover notas do inbox |
| [[40-skills/log-session/SKILL\|log-session]] | No fim de cada sessão de trabalho num projeto |
| [[40-skills/propose-change/SKILL\|propose-change]] | Alterar um ficheiro de escrita via revisão |
