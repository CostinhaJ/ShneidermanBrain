# Inbox

Entrada de notas soltas, ideias e excertos. Escrita livre.
O agente [[50-agents/inbox-triage]] classifica cada nota e move-a para o sítio certo (projeto, área ou conhecimento), deixando uma linha no `log/` do destino.

Notas por triar: nenhuma.
