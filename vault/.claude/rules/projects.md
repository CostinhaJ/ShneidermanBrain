# Regras de projetos

- A forma de um projeto é a de `10-projects/_template/`. Um subprojeto repete essa forma dentro da pasta do projeto-pai.
- `INDEX.md` cabe numa página: resumo, estado atual, próximas ações, mapa de ficheiros.
- `CONTEXT.md` só tem o que é estável: objetivo, âmbito, stakeholders, restrições, glossário.
- Uma decisão por ficheiro em `decisions/`, nomeado `NNNN-titulo-curto.md`, numeração sequencial por projeto.
- `log/AAAA-MM.md`: entradas novas no topo, 5 a 10 linhas cada. Decisões não ficam no log.
- Um projeto novo cria-se com [[40-skills/create-project/SKILL]]. Cada ficheiro é criado com Write já preenchido, sem copiar e editar.
